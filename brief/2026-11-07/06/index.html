Google hands gVisor and its agent stack to the CNCF

Google is donating gVisor, Agent Substrate and OpenRL to the Cloud Native Computing Foundation, putting its AI agent infrastructure under neutral governance. gVisor, open sourced by Google in 2018, runs a lightweight kernel in user space to intercept system calls, adding isolation between containers and the host system, and is used by Anthropic and OpenAI to run untrusted code. Agent Substrate 1.0, now generally available on Google Kubernetes Engine, lets agents pause when idle and resume without rebuilding their runtime, while OpenRL coordinates reinforcement learning training on a user’s own Kubernetes setup.

WHY IT MATTERS FOR TECH

Sandboxing is becoming core infrastructure for agents that run untrusted code, and neutral ownership is Google’s bid to make its stack the default.
