Hijacked Optimizely scripts served a card skimmer to visitors of CNN, BBC and Zoom

An attacker exploited a flaw in Optimizely's Web Experimentation service to inject malicious code into the scripts that customer websites load from it, reaching visitors at 178 organisations including CNN, the BBC and Zoom. The code swapped cryptocurrency wallet addresses for the attacker's own and added a card skimmer that captured card numbers, expiry dates and security codes, while iPhones were served exploit kits that researchers say did not take over any device. Optimizely says it has fixed the flaw and removed the code, and researchers counted about 7,040 dollars in cryptocurrency sent to the attacker's wallets.

WHY IT MATTERS FOR TECH

A single compromised supplier script ran on hundreds of high-traffic sites at once, so visitors had no way to tell a trusted page had turned hostile.
