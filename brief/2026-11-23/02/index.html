Gemini API gains Tool Retrieval so agents load tool details only when needed

Google has added Tool Retrieval to the Gemini API in preview, letting agents keep a large tool library on standby and load a tool's full parameter schema only when the model asks for it. The model still sees every tool's name and description, so it can find the right one, while the schemas stay out of the prompt until needed, which cuts input tokens and keeps tool choice accurate as the library grows. The feature works with Gemini 3.6 and later models, including all Gemini 4 models, carries no separate charge, and also applies to tools exposed through remote MCP servers.

WHY IT MATTERS FOR TECH

Agents that juggle dozens or hundreds of tools can stay fast and accurate without paying the token cost of describing every tool on every call.
