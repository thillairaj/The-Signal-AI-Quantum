Claude Code settings files leak passwords and keys in public GitHub repos

Security researchers at Apiiro found 1,122 public copies of Claude Code's settings file holding at least one secret, including database passwords, cloud keys and tokens. The file, .claude/settings.local.json, records commands a user approved with 'don't ask again', word for word, so passwords typed into a command are saved in plain text. Apiiro counted 1,379 secrets in current copies and 2,539 in total across 1,994 repositories once older versions, forks and shared settings files are included, and says the fix starts with rotating every exposed credential.

WHY IT MATTERS FOR TECH

Secrets saved in agent settings files leak into public repos, so teams need to treat agent folders like credential stores and scan their history.
