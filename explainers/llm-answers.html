How an LLM Answers a Prompt

You type a question and an answer appears, token by token, as if someone were writing it. Nobody is. A large language model is doing one thing, over and over: working out what token comes next. Tap any part to see how, in simple words first and then in more depth.

      Watch one word get chosen

      The prompt is: The cat sat on the… and the model must pick the next token. These numbers are an illustration, invented for this example in the pattern a real model produces; real probabilities come from the model itself.

      mat46%
      floor18%
      chair11%
      roof7%
      sofa6%
      everything else12%

      At a low temperature the model takes mat almost every time. Turn the temperature up and floor, chair and even roof get their turn, which is why the same prompt can answer differently twice.
