Google ADK — Agent Development Kit

Agent Frameworks (Code)

Agent Development Kit: Google's open-source framework for building and deploying agents, designed to work with Google's models and Vertex AI while also supporting others. It puts unusual emphasis on evaluation and deployment tooling alongside the agent code itself.

Key factMaker: Google. Open-source; launched in 2025 as part of Google's agent platform push.
Leader lensThe natural framework choice inside Google Cloud estates. It is newer than its main rivals, so expect a faster-moving API and verify enterprise references.
