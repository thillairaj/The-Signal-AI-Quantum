AuG

Microsoft AutoGen

Agent Frameworks (Code)

Microsoft Research's framework for conversational multi-agent systems, where agents talk to each other and to humans in order to solve tasks. It is widely used in research and prototyping, and its ideas fed into Microsoft's broader agent framework work. Since October 2025, AutoGen continues in the Microsoft Agent Framework, the successor framework that merges AutoGen with Semantic Kernel; the original framework is in maintenance mode.

Key factMaker: Microsoft. Open-source. Its multi-agent conversation patterns influenced many later frameworks.
Leader lensStrong research lineage and community. Enterprise buyers should check how it lines up with Microsoft's currently supported agent frameworks before committing a platform decision to it.
