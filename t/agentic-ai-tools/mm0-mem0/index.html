Memory & Retrieval

A memory layer for AI agents and applications that extracts, stores and retrieves persistent memories about users and past interactions, so agents remember across sessions instead of replaying entire conversation histories every time.

Key factMaker: Mem0. Open-source core with a hosted commercial platform.
