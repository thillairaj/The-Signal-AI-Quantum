Fargate — Serverless Containers

Compute

A serverless way to run containers on ECS or EKS: you specify the CPU and memory each task needs and AWS runs it without you managing the underlying instances. It trades a higher per-unit price for the removal of patching, scaling and capacity management of container hosts.

Key factWith Fargate you pay for the vCPU and memory allocated to each task, for the time it runs — there are no idle servers to pay for.
Leader lensFargate is the right default for small platform teams. The premium over EC2 is usually smaller than the engineering time it returns.
