EC2 — Elastic Compute Cloud

Compute

Virtual servers in the cloud and the original AWS compute service: you choose the processor, memory and storage size, install your own operating system and software, and pay while the instance runs. EC2 is what a company rents instead of buying physical servers, and it remains the default home for migrated legacy workloads.

Key factEC2 launched in 2006 and offers hundreds of instance types; capacity bought on demand can be stopped, resized or moved far faster than any physical hardware.
Leader lensEC2 is the easiest service to over-buy. Untended instances running nights and weekends are the single most common source of AWS waste.
