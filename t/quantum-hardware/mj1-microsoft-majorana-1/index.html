Microsoft Majorana 1

Exotic Approaches

Majorana 1 is Microsoft's first chip built around a material stack it calls a topoconductor, intended to host Majorana modes, announced in February 2025 with eight topological qubits. Microsoft frames it as the first step on a path to a million qubits on a single chip. The announcement attracted both attention and requests from physicists for more complete published evidence.

Key factMicrosoft's Majorana 1 was announced alongside a Nature paper on its single-shot readout method, and the chip is built from indium arsenide and aluminium.
Leader lensWatch this one through the scientific literature, not the keynote. If validated, it changes the hardware race; if not, it is a very expensive detour.
