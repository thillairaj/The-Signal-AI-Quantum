Algorithm Negotiation

Crypto-Agility & Inventory

The protocol mechanism by which two systems agree which algorithms to use, as TLS does for cipher suites and key-exchange groups. Negotiation is what makes gradual migration possible, but it must be protected against downgrade attacks that force weaker choices. Policy should pin minimums rather than let peers drift to the weakest common option.

Key factTLS 1.3 authenticates the full handshake transcript, so an attacker cannot silently strip post-quantum options from a negotiation without detection.
Leader lensConfigure negotiation deliberately: offer PQC hybrids broadly, and set floors so legacy peers cannot drag you back.
