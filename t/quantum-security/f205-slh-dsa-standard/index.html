FIPS 205 — SLH-DSA Standard

NIST Standards & Algorithms

The FIPS standard specifying SLH-DSA, the stateless hash-based signature scheme, finalised in August 2024. It exists so the ecosystem is not wholly dependent on lattice assumptions. Its large signatures limit it to roles where size is tolerable, such as root certification and code signing.

Key factFIPS 205 defines twelve parameter sets trading signature size against speed, all built purely from SHA-2 or SHAKE hash functions.
Leader lensKnow this standard exists as your insurance policy if lattice cryptography is ever weakened.
